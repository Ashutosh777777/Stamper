```python
# series_calculator.py

def calculate_series(n):
    """
    Calculate the sum of the series 1 - 1/3 + 1/5 - 1/7 + ... up to n terms.
    
    Args:
    n (int): The number of terms in the series.
    
    Returns:
    float: The sum of the series multiplied by 4.
    """
    total = 0.0
    for i in range(n):
        # Calculate the sign of the term, alternating between 1 and -1
        sign = (-1) ** i
        # Calculate the denominator of the term, which is 2*i + 1
        denominator = 2 * i + 1
        # Add the term to the total
        total += sign / denominator
    # Multiply the total by 4
    total *= 4
    return total

def main():
    # Calculate the sum of the series for the first 10,000 terms
    n = 10000
    result = calculate_series(n)
    print(f"The sum of the series for the first {n} terms, multiplied by 4, is: {result}")

if __name__ == "__main__":
    main()

```

Output:
The sum of the series for the first 10000 terms, multiplied by 4, is: 3.1414926535900345


**Explanation**

The `calculate_series` function calculates the sum of the series up to `n` terms. It uses a loop to iterate over each term, calculating the sign and denominator of the term, and adding it to the total. The total is then multiplied by 4.

The `main` function calls `calculate_series` with `n = 10000` and prints the result.

**Note**

This program uses a simple iterative approach to calculate the sum of the series. For larger values of `n`, a more efficient approach may be needed to avoid numerical instability or performance issues.
